# Koblenzer Puppenspiele Block Theme – Phase 1.7

Ergänzung für Phase 2.1:
- Header/Navigationsstand aus Phase 1.6 bleibt erhalten.
- Startseite zeigt mit installiertem Plugin „Koblenzer Puppenspiele – Inhalte“ automatisch die nächsten 5 Vorstellungen.

- Termine selbst liegen bewusst im Plugin, nicht im Theme, damit die Daten einen späteren Theme-Wechsel überstehen.
