# Anleitung: Homepage kostenlos pflegen und reparieren

Diese Anleitung erklärt die wichtigsten Funktionen des KP Editor V2 in einfacher Sprache.

## 1. Was der Editor macht

Mit dem KP Editor V2 können Sie Inhalte direkt auf der Homepage ändern, ohne Programmiersprache zu kennen.

Sie können zum Beispiel:
- Texte ändern
- Überschriften anpassen
- Bilder austauschen
- Buttons beschriften
- kleine Reparaturen auslösen

## 2. So arbeiten Sie sicher

1. Öffnen Sie die Homepage mit dem KP Editor.
2. Klicken Sie unten oder im KI-Overlay auf **✦ KI bearbeiten**.
3. Tippen Sie Ihren Wunsch in normalem Deutsch ein.
4. Klicken Sie auf **Sofort umsetzen**.
5. Prüfen Sie die Vorschau.
6. Erst wenn alles gut aussieht, speichern Sie die Änderung.

## 3. Kostenloses KI-Routing

Der Editor nutzt standardmäßig die kostenlose **Gemini 2.0 Flash**-Route.

Wenn Gemini ein Limit erreicht oder ausfällt, wechselt das System automatisch auf **Ollama auf dem eigenen Rechner**.

### Umschalten

Im KI-Overlay gibt es ein Feld **Routing**:
- **Gemini 2.0 Flash** = kostenloser Cloud-Modus
- **100% Lokal (Ollama)** = komplett ohne Cloud

Wenn Sie einen eigenen kostenlosen Gemini-Key haben, können Sie ihn im Feld **Gemini einmalig verbinden** eintragen.

## 4. Reparieren mit Sprache

Wenn Ihr Browser Sprache unterstützt:
- Klicken Sie im KI-Overlay auf **🎙 Sprechen**
- Sprechen Sie Ihren Wunsch auf Deutsch
- Der Text wird übernommen und kann direkt ausgeführt werden

## 5. Wenn etwas nicht klappt

### Gemini antwortet nicht

Dann macht der Editor automatisch weiter mit der lokalen Ollama-Route.

### Ollama ist nicht erreichbar

Starten Sie Ollama auf Ihrem Computer. Der lokale Dienst läuft normalerweise auf:
- `http://127.0.0.1:11434`

### Änderungen werden nicht gespeichert

Dann prüfen Sie:
- ob Sie angemeldet sind
- ob der Browser die Seite neu geladen hat
- ob Sie am Ende auf **Speichern** geklickt haben

## 6. Empfehlung für den Alltag

- Nutzen Sie zuerst kurze, klare Sätze.
- Machen Sie immer eine Vorschau-Prüfung.
- Speichern Sie nur, wenn die Änderung wirklich richtig aussieht.
- Wenn der Cloud-Modus stört, stellen Sie einfach auf **100% Lokal (Ollama)** um.

## 7. Merksatz

**Gemini ist der kostenlose Standard, Ollama ist die sichere lokale Reserve.**
